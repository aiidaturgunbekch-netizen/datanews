# DataNews — инструкция администратора

## 1. Однократная настройка в Vercel (≈5 минут)

Панель управления, регистрация, модерация и статистика хранят данные на сервере.
Без этого шага сайт работает, но вход администратора и регистрация выдадут
«Сервер ещё не настроен».

1. **База данных.** Vercel → ваш проект → **Storage** → **Create / Connect** →
   **Upstash for Redis** (бесплатный тариф) → подключить к проекту.
   Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
2. **Пароль администратора.** Vercel → **Settings → Environment Variables**:
   - `ADMIN_PASSWORD` — ваш пароль (длинный, никому не сообщайте);
   - `AUTH_SECRET` — любая длинная случайная строка (необязательно, но желательно).
3. **Redeploy** (Deployments → ⋯ → Redeploy), чтобы переменные применились.
4. **Реквизиты оплаты и цены** — в файле `src/config/site.ts`
   (`PAYMENT_DETAILS` — номер MBank / O!Деньги / карты; `PLANS` — цены и лимиты).

## 2. Где вы управляете сайтом

Панель открывается **только по секретному адресу**:

```
https://<ваш-сайт>/#admin
```

Гости кнопку панели не видят — у них в шапке только «Личный кабинет»
и «Разместить». После вашего входа в шапке появляется зелёная кнопка
🛡 «Панель управления».

| Вкладка | Что там делать |
|---|---|
| **Модерация** | Новые публикации гостей с фото, датой, адресом и контактами автора. Кнопки: **Одобрить** (сразу на сайте), **Отклонить** (с причиной — автор её увидит), **Исправить**. Жёлтый счётчик = сколько ждут. |
| **Публикации** | Все события сайта: поиск, редактирование, удаление, **Новая публикация** (ваши публикуются сразу, без модерации). |
| **Пользователи** | Зарегистрированные гости, их тариф и номер платежа. **Подтвердить оплату** открывает им доступ к публикациям, **Платёж не найден** — отказ, **Приостановить** — закрыть доступ. Жёлтый счётчик = платежи на проверке. |
| **Статистика** | Посетители и просмотры за сегодня / 7 / 30 / 90 дней, график по дням, популярные разделы, источники переходов (Instagram, Google…), города, устройства, язык. Ваши собственные визиты и поисковые роботы не считаются. |

## 3. Путь гостя (платная регистрация → модерация)

1. Гость нажимает «Личный кабинет» или «Разместить» → **Регистрация**:
   имя, e-mail, телефон, пароль, тариф (Частный 500 сом / Организатор 2 000 сом).
2. Оплачивает по реквизитам и вводит номер транзакции → статус «Оплата проверяется».
3. **Вы** во вкладке «Пользователи» сверяете платёж и жмёте «Подтвердить оплату».
4. Гость добавляет событие с фото/афишей → статус «На модерации».
5. **Вы** во вкладке «Модерация» одобряете или отклоняете с причиной.
6. Одобренное событие появляется на сайте; отклонённое автор может исправить
   и отправить повторно (оно снова попадёт к вам).

Гость не может сам поставить событие в бегущую строку «Срочно» или
отметить «Проверено» — это делаете только вы.

## 4. Локальный запуск для проверки

```bash
npm install
npm run dev        # http://localhost:3000, панель: http://localhost:3000/#admin
```

Без подключённого Redis данные хранятся в памяти до перезапуска,
пароль администратора — значение `ADMIN_PASSWORD` или `admin-dev`.
