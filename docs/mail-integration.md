# Редакционная почта → «Материалы из почты» (только Preview)

Письма из ящика **datanews.kg7@gmail.com** передаёт на сайт скрипт Google Apps Script
(`tools/gmail-apps-script/Code.gs` и файл настроек `appsscript.json`). Сайт сохраняет письмо во **«Материалы из почты»** панели администратора.

Что важно знать заранее:

- **Письмо само ничего не публикует.** Редактор нажимает «Подготовить черновик» → форма → «Сохранить черновик в «Модерацию»».
  На сайте материал появляется **только после «Одобрить»** во вкладке «Модерация».
- **«Подтверждено по первоисточнику»** — отдельная отметка в форме, ставится только после сверки. Письмо с официального адреса — это «получено от организации», а не подтверждение.
- **Приём работает только в Preview.** На Production он отключён в коде, даже если секреты заданы.
- **Приём по умолчанию выключен.** Включается и выключается в панели: «Статистика» → «Приём почты».
- **Таймер (проверка каждые 15 минут) в этой инструкции не включается.** Сначала — ручной тест одного письма.
- **Минимальные права скрипта** — ровно два разрешения, они записаны в `appsscript.json`:
  - «Просмотр писем и настроек электронной почты» (`gmail.readonly`) — **только чтение**: отправлять, удалять, перемещать письма и ставить ярлыки скрипт не может;
  - «Подключение к внешней службе» (`script.external_request`) — отправка данных на сайт, только по адресу `INGEST_URL`.
- **PDF на этом этапе не обрабатываются**, доступа к Google Диску и Документам у скрипта нет. Сайт получает только текст письма и фото JPG / PNG / WEBP.

Никакие секреты не пишутся в код, в GitHub, в эту инструкцию и в журнал скрипта.

---

## 1. Vercel — пропуск для скрипта через защиту Preview

Preview закрыт входом Vercel, поэтому скрипту нужен отдельный пропуск. Защиту целиком **не отключать**.

1. Vercel → проект DataNews → **Settings → Deployment Protection**.
2. Раздел **Protection Bypass for Automation** → создать секрет. Название: «Apps Script — почта DataNews».
3. Скопировать значение в надёжное место (менеджер паролей). В чат, письма и документы не вставлять.

Риски пропуска:

- он открывает внешнюю страницу входа Vercel для **всех** Preview-сборок проекта;
- вход в панель, список писем и приём писем он **не** открывает: для них нужны пароль администратора и подпись скрипта.

Отключение одним действием: удалить этот секрет в том же разделе. Скрипт сразу перестанет проходить.

## 2. Vercel — проверить секрет подписи

Переменная `MAIL_INGEST_SECRET` уже задана для Preview. Убедиться можно в панели: «Статистика» → «Приём почты» → «Секрет подписи … задан».

## 3. Google — создать скрипт

1. Войти в Google **под datanews.kg7@gmail.com**. Это важно: скрипт работает с почтой того аккаунта, под которым создан.
2. Открыть https://script.google.com → **Новый проект**. Назвать: «DataNews — почта».
3. Удалить содержимое файла `Code.gs` и вставить текст из `tools/gmail-apps-script/Code.gs` этой ветки.
4. **Файл настроек с правами:**
   - **Настройки проекта** (шестерёнка слева) → поставить галочку **«Показывать файл манифеста appsscript.json в редакторе»**;
   - вернуться в **Редактор** (значок `< >`) → открыть файл **appsscript.json**;
   - заменить его содержимое текстом из `tools/gmail-apps-script/appsscript.json` этой ветки.

   Этот файл сам подключает встроенную службу **Gmail API** и ограничивает права двумя разрешениями. Добавлять другие службы (Drive, Docs) **не нужно**.
5. **Сохранить** (значок дискеты). Слева в разделе **«Службы»** должна появиться **Gmail**.
6. **Скрипт никому не открывать** для совместного редактирования: его свойства видят все редакторы.

## 4. Google — свойства скрипта (секреты)

**Настройки проекта** (шестерёнка) → **Свойства скрипта** → добавить три свойства:

| Свойство | Значение |
|---|---|
| `INGEST_URL` | `https://datanews-git-claude-datanews-events-moderation-st-d45971-aiida2.vercel.app/api/sources?mail=ingest` |
| `INGEST_SECRET` | то же значение, что `MAIL_INGEST_SECRET` в Vercel (Preview) |
| `VERCEL_BYPASS` | пропуск из шага 1 |

Затем в редакторе выбрать функцию **`checkSetup`** → **Выполнить**.

- Google один раз попросит разрешения. **Перед «Разрешить» проверьте список — в нём должно быть ровно два пункта** (формулировка Google может немного отличаться):
  - «Просмотр писем и настроек электронной почты» (только чтение Gmail);
  - «Подключение к внешней службе».

  Если в списке есть «Чтение, создание, отправка и удаление писем», «Google Диск», «Google Документы» или что-то ещё — **не разрешайте**: значит, `appsscript.json` не сохранён или старый.
- Появится «Приложение не проверено» — это нормально для собственного скрипта: **Дополнительно → Перейти к проекту «DataNews — почта» (небезопасно) → Разрешить**.
- Если раньше вы уже давали скрипту более широкие права: myaccount.google.com → **Безопасность** → **Сторонние приложения и сервисы** → «DataNews — почта» → **Удалить доступ**, затем авторизуйтесь заново.
- В **журнале выполнения** должно быть три строки «…: задан» и «Настройки в порядке.». Значения не выводятся.

## 5. Сухой прогон — ничего не отправляет

Выбрать функцию **`dryRun`** → **Выполнить**. В журнале появятся 3 последних письма за 30 дней: от кого, тема, размер текста, вложения и что из них было бы передано.

Скрипт при этом **ничего не отправляет и ничего не меняет** — он только читает письма.

## 6. Тест одного письма

1. С **личной** почты отправить на datanews.kg7@gmail.com письмо:
   - тема: **ТЕСТ DataNews**;
   - текст: «Тестовое объявление 30 ноября 2026 года в 10:00. По адресу: ул. Тестовая, 1, г. Бишкек.»;
   - вложение: одно небольшое фото (JPG или PNG, до 2 МБ).
2. Панель Preview → «Статистика» → «Приём почты» → **Включить приём**.
3. Apps Script → функция **`processTest`** → **Выполнить**. Она отправляет **только** письма с темой «ТЕСТ DataNews».
   - В журнале должно быть: «Принято сайтом: «ТЕСТ DataNews» — stored (new)».
   - В самом Gmail ничего не меняется: ярлыков нет, письмо остаётся на месте. Скрипт запоминает обработанные письма у себя в свойстве `PROCESSED_IDS`.
4. Панель → **Выключить приём**.

## 7. Проверка: письмо в «Материалах из почты», но не на сайте

1. Панель → **«Материалы из почты»** → вкладка «Новые». Должно быть письмо «ТЕСТ DataNews»:
   - отправитель и дата получения;
   - «Дата события (из текста)»: 30 нояб. 2026 г., 10:00;
   - «Место»: ул. Тестовая, 1, г. Бишкек;
   - пометки «Требует проверки» и «Неизвестный отправитель» — он не в списке госорганов, это нормально;
   - фото: «Показать фото».
2. На **сайте** Preview (главная, лента, поиск) объявления «Тестовое объявление» **нет**.
3. В «Модерации» и «Публикациях» ничего нового нет.
4. **Повтор:**
   - снова «Включить приём» → `processTest` → в журнале «Отправлено писем: 0»: скрипт помнит письмо;
   - второй записи в «Материалах из почты» нет;
   - «Выключить приём».
5. **По желанию** — проверка пути до черновика:
   - «Подготовить черновик» → форма заполнена из письма → «Сохранить черновик в «Модерацию»»;
   - черновик виден в «Модерации», но **не на сайте**;
   - затем «Отклонить» его в «Модерации». «Одобрить» для теста не нажимать.
6. Тестовое письмо в «Материалах из почты» → **Отклонить**.

## 8. Как отключить интеграцию

Любое из действий:

- **сразу:** панель → «Приём почты» → **Выключить приём**;
- **сразу:** Vercel → Deployment Protection → удалить пропуск «Apps Script — почта DataNews»;
- **сразу:** не запускать скрипт или удалить проект Apps Script;
- **после пересборки Preview:** `MAIL_INGEST_ENABLED=0` или удалить `MAIL_INGEST_SECRET` в Vercel.

## 9. Позже — таймер

Только после успешного теста и отдельного решения: Apps Script → **Триггеры** (будильник) → Добавить → функция `processNew`, «По времени», «Каждые 15 минут».

`processNew` отправляет новые письма за 3 дня, кроме служебных писем Google и Claude.

## Что передаётся и хранится

| Что | Как |
|---|---|
| Отправитель, тема, дата получения, ссылка на письмо в Gmail | сохраняются |
| Текст письма | до 50 000 знаков |
| Проверка подлинности (SPF / DKIM / DMARC) | сохраняется |
| Фото JPG / PNG / WEBP до 2 МБ (всего до ~3 МБ на письмо) | временная копия на 30 дней; на сайт попадает, только если редактор выбрал его в черновике |
| PDF | на этом этапе **не обрабатываются**: передаются только название и размер — откройте письмо в Gmail |
| Остальные вложения | только название — откройте письмо в Gmail |
| Ссылки в тексте | сохраняются текстом, сайт их не открывает |
